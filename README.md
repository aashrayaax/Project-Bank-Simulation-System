# Bank Simulation System 🏦

A full-stack web-based banking simulation application built with Python (Flask) for the backend logic and SQLite for persistent data storage[cite: 1]. This project simulates core financial operations with built-in input validation, error handling, and transaction logging[cite: 1].

## 🚀 Features

* **User Authentication**: Secure registration and login using user credentials and PIN verification.
* **Core Banking Operations**: 
  * Deposit and withdrawal capabilities with real-time balance updates.
  * Inter-account fund transfers via recipient email lookup.
* **Transaction Logging**: Automated tracking of deposits, withdrawals, and transfers with timestamps.
* **Database Management**: Integrated script (`showdata.py`) for quick command-line database inspection.

## 🛠️ Tech Stack

* **Backend**: Python, Flask, SQLite[cite: 1]
* **Frontend**: HTML5, CSS3, JavaScript[cite: 1]
* **Tools**: Git, GitHub, VS Code[cite: 1]
